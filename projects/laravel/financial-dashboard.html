AI-Driven Automated Website Lead Generator & Upgrader

An automated lead-generation pipeline that uses AI to discover prospective business websites, evaluate their feature gaps, and dynamically build upgraded drop-in replacement prototypes.

This project was made to bring in more customers by sending them a testable improved version of their site without putting hours into working on a site when it isn't even confirmed that the customer wants a new site.

What this project does exactly is:

  1. Find websites online with AI.
  2. Scrape the websites and compare the features on the site with a customisable feature list.
  3. Create an improved version of the site with all the old features, plus the ones in the feature list that were not yet present.
  4. Make an SEO file of the original and the new website.

Token AI optimisation

To not make generating a whole website too expensive, I made sure to be as optimal with the prompting as I could be. I also made a feature that would make the tokens 50% cheaper by using a Batches API, but that does make it take way longer to generate. The average cost for generating a website with this project was 5 euros, and it would take around 15–30 minutes to generate.

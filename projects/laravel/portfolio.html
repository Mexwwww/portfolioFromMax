Modular Developer Portfolio & Static Architecture Rewrite

A high-performance personal portfolio originally built in Laravel, fully rewritten into static HTML and JavaScript for free hosting and faster load times.

This is this exact website. I originally designed and built this portfolio using Laravel PHP, but I later chose to completely rewrite it into a pure static architecture. This change allows me to host the site entirely for free while achieving significantly quicker load times, all while maintaining a clean, professional software developer aesthetic inspired by developer tooling and GitHub dashboards.

Architecture & Transition

While the site started on a PHP backend utilizing Blade templating, it now runs entirely on lightweight static files, Bootstrap 5, and client-side JavaScript. It is styled completely with custom CSS featuring darkslate surfaces, subtle cyan accents, and Fira Code typography. Navigation is built around natural mouse interaction with an Escape key shortcut for quick backward navigation.

Dynamic Data & Project Loading

To keep the project modular and easy to update without managing a heavy server backend, project details and category lists are driven by a centralized JSON dataset fetched dynamically on the client side. This preserves the ease of adding new work while keeping the site lightning-fast and natively compatible with static hosting providers like GitHub Pages.

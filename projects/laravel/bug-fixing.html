Local AI Chat Interface & Automated Database Reporting Extension

A custom web platform that parses structured commands from a local AI's chat replies to query isolated databases and generate automated reports[cite: 6].

I worked with an existing, locally-run AI by building a custom website around it, with its own chat area[cite: 6].

By giving the AI a specific set of rules, I got it to write certain things in its replies in a specific format. My own code on the website could then read that format out of the AI's response and use it to do things the AI itself wasn't able to do directly, such as getting information from a database the AI had no direct access to, and using that information to generate a report with visual graphs and text[cite: 6].

How it worked

I gave the AI a rule that basically came down to: if the user asks for a report on, for example, the profit made in the last 2 years of the company, write the years and the information you want inside {} in this specific format[cite: 6]:

{time:"2"; scale:"years"; format:"report"}

My code on the website would take the AI's response shown in the chat area and pull that tagged information out of it. It would then use that to get the needed information from the database, and send it to a separate AI agent that generated the report. That agent sent back the formatted information, which my code then used to generate graphs, with the rest of the report shown as text[cite: 6].
